Who Can Reach You Back

Experiment № 115 · November 9, 2026

Tarjan, 1972: split a directed graph into its strongly connected components, the groups where everyone can reach everyone, in a single depth-first walk. Each node remembers one number: the oldest open node it can climb back to.

Edit it: tap one node, then another, to add an arrow between them, or remove it if it's already there. Then run again.

Experiment № 115 · The story

Who Can Reach You Back

Why I picked it

This gallery already has a lot of graphs: Kahn ordering tasks that depend on each other, Kruskal joining strangers, Hierholzer crossing every bridge, Floyd catching a single loop. Kahn's sort has a quiet escape hatch: if there is a cycle, it just stops and gives up. I wanted the algorithm that answers what that cycle actually is, and every other one in the graph too. Robert Tarjan published it in 1972, when he was in his mid-twenties, and it is still what compilers, package managers and spreadsheet engines use to find knots of things that all depend on each other.

What I enjoy about it

The economy of it. A depth-first walk numbers every node as it arrives, and each node carries one extra number, its "low": the oldest node still on the stack that it has found a way back to. A pink arrow pointing back into the stack pulls that number down, and when the walk returns, the parent takes the child's low as well. When a node finishes and its low still equals its own number, nothing below it got out, so it and everything pushed above it on the stack form one component. Pop them, colour them, carry on. Every arrow is looked at exactly once.

I also like a fact that falls out for free. The first component Tarjan closes is always one that nothing leaves; the next can only lead into that one, and so on. Press Condense at the end: every arrow between components points from a higher number to a lower one. The tangle was a tidy one-way flow all along, made of knots.

Something you might take away

Any mess of one-way relationships, whether imports, people who owe each other, or pages linking pages, is a simple ordered chain once you shrink each mutual knot to a single point. When something looks hopelessly circular, look for the groups where everyone really can reach everyone else. Usually there are only a few, and between them the arrows all run the same way.
